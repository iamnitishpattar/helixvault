Digital data is expanding much faster than our ability to store it. Magnetic tapes and hard drives wear out every few years, and running massive air-conditioned server farms consumes enormous electrical power. DNA offers a compelling way out: it packs petabytes into microscopic volumes and stays readable for centuries without electricity. However, moving DNA storage from wet-lab experiments into usable software remains difficult. Most existing tools are isolated scripts with no web interface, zero encryption, and no mechanism to protect files against physical degradation.

In this work, we present HelixVault, an open-source web platform that handles the full digital-to-DNA lifecycle. We wrote a custom Base-3 codec that solves the homopolymer problem: chemical synthesizers struggle when identical nucleotides repeat, so our mapping strictly prevents identical consecutive bases by construction. Before encoding, files are encrypted with AES-256-CBC using PBKDF2 key derivation. We then apply Reed-Solomon RS(255, 205) error correction, which can rebuild up to 25 damaged bytes in each codeword. For security and camouflage, HelixVault can also hide payloads inside real E. coli genomic sequences pulled from NCBI. The platform includes an interactive plasmid cloning tool for pUC19/pBR322 vectors, an automated biosecurity screen, and a local Groq AI assistant. Built with FastAPI and React, our implementation recovered 100% of tested files under simulated mutations.
